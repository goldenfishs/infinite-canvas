# 乐米无限画布

基于 infinite-canvas v0.20.0。主站原有登录、分组授权和计费保持不变，画布项目、素材仍保存在当前浏览器，公共设备请使用独立浏览器配置文件。

主站自定义用户菜单指向 `https://canvas.lumivia.cn/canvas`。画布通过主站域名下独立的 `/canvas-connect/` 授权页请求用户确认。主站登录令牌仅随同源授权请求送往授权服务，不交给画布前端、不持久化。服务通过本机 Sub2 用户接口绑定或复用当前用户的生图专用 Key，根据该 Key 获取图片模型。图片请求只转发至固定的生图和改图路径。价格展示为授权时读取的分组参考价，账单取决于主站实际规则。

授权码只能由发起授权的浏览器在 90 秒内兑换一次；画布会话使用独立的 Secure、HttpOnly 主机 Cookie，有效期 8 小时。退出画布或重启授权服务会结束画布会话；仅退出主站不等同于退出画布。用户也可在主站禁用或删除画布专用 Key，阻止后续扣费。原版的自备渠道功能保留，视频不经过本授权服务。

构建：在 `web` 安装锁文件依赖，运行 `bun run typecheck` 和 `bun run build`。发布包包含 `web/dist`（归档名 `dist`）与 `lumivia/`。香港主机使用 Ubuntu 的 `python3-aiohttp`、systemd、Nginx 和独立静态站容器；`deploy.sh` 通过本机健康检查后切换 Nginx，保存上一版两个站点配置供回退。请按环境确认主站地址、现有站点名和生图组 ID 后再部署。
