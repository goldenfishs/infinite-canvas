# 乐米画布

基于 infinite-canvas v0.20.0。主站原有登录、分组授权和计费保持不变，画布项目、素材仍保存在当前浏览器，公共设备请使用独立浏览器配置文件。

主站自定义用户菜单指向 `https://api.lumivia.cn/canvas-entry`。入口清理查询参数后嵌入乐米画布。画布通过主站同源的账号同步页读取当前登录状态，在「配置 → 渠道」显示账号、内置生图渠道和当前账号个人 Key 对应的对话分组。用户在主站切换账号或退出后，画布会清除旧账号并同步当前状态。

主站登录令牌只随同源请求发往授权服务。服务通过 Sub2 用户接口确认生图分组权限，并复用或创建属于当前用户的专用 Key。每次生图或改图都要重新授权，一次性凭证限对应请求动作和浏览器校验值。画布不保存独立登录会话，内置渠道不参与配置导入或导出。价格显示当前分组提供的参考价，账单以主站实际规则为准。生图/改图使用平台专用 Key，主站用户密钥列表、详情、修改和删除接口由同机独立服务保护；主站使用记录保留原账单归属。旧版通过普通接口创建的 Key 没有可靠的创建者标记，不按名称删除或接管。

文本节点和右上角 Agent 自动使用当前用户已有的有效对话 Key，不在前端返回密钥。对话按选择的 Key 与模型重新授权，流式或非流式请求均通过主站原网关计费。没有可用对话 Key 时，配置页提供主站密钥入口。画布内输入“创建一个便签：……”可以添加文字节点。

生图历史先读取轻量索引、分批显示缩略图，打开一条记录时才加载它的原图与参考图。升级前的本机记录可通过「读取较早的本机记录」分批打开，原始记录不会被迁移到服务器。

「云图库」属于当前主站账号；用户可在生图结果点击「存云端」或手动上传图片。云图库不自动保存本机历史、参考图、视频或画布工程。服务端按文件大小计量，默认每用户 1 GiB，单张最多 32 MiB。主站管理员可在「云图库 → 存储管理」调整默认或单用户额度；降低额度不删除既有图片。云图库全站默认上限为 8 GiB（可通过服务环境变量 `CANVAS_STORAGE_LIMIT_BYTES` 调整），磁盘独立预留 4 GiB。迁移、备份时同时保留 systemd 管理的 `/var/lib/lumivia-canvas`，包括 SQLite 和原图文件；使用停写快照或一致性备份。

构建：在 `web` 安装锁文件依赖，运行 `bun run typecheck` 和 `bun run build`。发布包包含 `web/dist`（归档名 `dist`）与 `lumivia/`。香港主机使用 Ubuntu 的 `python3-aiohttp`、systemd、Nginx 和独立静态站容器；`deploy.sh` 通过本机健康检查后切换 Nginx，保存上一版两个站点配置供回退。主站迁移时须同步备份 `/etc/lumivia-canvas/key-seed`；接口过滤服务故障时密钥管理应保持关闭，不能直接放行至 Sub2。请按环境确认主站地址、现有站点名和生图组 ID 后再部署。
