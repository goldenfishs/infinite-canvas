# 乐米画布

基于 infinite-canvas v0.20.0。主站原有登录、分组授权和计费保持不变，画布项目、素材仍保存在当前浏览器，公共设备请使用独立浏览器配置文件。

主站自定义用户菜单指向 `https://api.lumivia.cn/canvas-entry`。入口清理查询参数后嵌入乐米画布。画布通过主站同源的账号同步页读取当前登录状态，在「配置 → 渠道」显示账号和内置生图渠道。用户在主站切换账号或退出后，画布会清除旧账号并同步当前状态。

主站登录令牌只随同源请求发往授权服务。服务通过 Sub2 用户接口确认生图分组权限，并复用或创建属于当前用户的专用 Key。每次生图或改图都要重新授权，一次性凭证限对应请求动作和浏览器校验值。画布不保存独立登录会话，内置渠道不参与配置导入或导出。价格显示当前分组提供的参考价，账单以主站实际规则为准。当前内置渠道支持生图与改图。

构建：在 `web` 安装锁文件依赖，运行 `bun run typecheck` 和 `bun run build`。发布包包含 `web/dist`（归档名 `dist`）与 `lumivia/`。香港主机使用 Ubuntu 的 `python3-aiohttp`、systemd、Nginx 和独立静态站容器；`deploy.sh` 通过本机健康检查后切换 Nginx，保存上一版两个站点配置供回退。请按环境确认主站地址、现有站点名和生图组 ID 后再部署。
