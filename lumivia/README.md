# 乐米画布

乐米画布沿用 Sub2 的登录、分组权限和用量账单。主站的自定义菜单指向 `https://api.lumivia.cn/canvas-entry`，画布站点仍是 `https://canvas.lumivia.cn`。主站登录令牌留在主站，画布使用与当前账号和请求绑定的一次性授权。生图和视频使用服务端专用 Key，主站上的独立服务保护这些 Key。Agent 和文本节点使用当前用户已有的对话 Key。

用户从生图工作台、画布节点或生成中心提交任务。离开页面后可到 `/jobs` 查看状态、核对任务编号或取消尚未发往上游的任务。成功的生成文件自动进入云图库。列表优先展示缩略图，打开原图、下载或导入画布时才读取完整文件。旧工作台历史、画布工程和本机素材仍保存在当前浏览器。

主站管理员可从画布顶栏打开 `/admin/canvas`，查看任务、内存和存储用量，调整默认或单用户配额、文件上限、保存期限、磁盘余量、队列并行数和可用模型分组。默认每人 1 GiB、全站 8 GiB、保留 4 GiB 磁盘余量，单图 32 MiB、单视频 128 MiB。默认每账号可有两条在途任务，队列同时处理一条，全站最多 30 条在途任务。服务进程达到 384 MiB 时暂缓受理和启动新任务，已送到主站的任务继续查询。保留期限默认不过期。改配额后保留旧文件，切换存储或保留期限影响新文件。

生图默认使用原分组及 BPS 异步接口。仅当 BPS 明确报告异步功能关闭，自动模式才改用同步上游。每个任务至多四张结果和八张参考图，参考图总上传上限为 64 MiB。已生成结果下载中断时，队列会用原任务编号重新取回文件。未知受理结果或取回多次失败可按任务编号到主站核账。视频支持 Seedance 原生任务、OpenAI 兼容表单和 BPS MiniMax-H3 JSON。管理员可为不同模型指定分组、协议、分辨率和可选时长。初始关闭视频，启用前须确认分组可用并配置对应模型及主站定价。画布没有独立的余额或价格规则。

V6K 的 MiniMax-H3 内容接口返回 303。与 BPS 2.21.6 搭配时，可在同一台机器部署 `docker compose -f lumivia/v6k-video.compose.yml up -d`，并把对应的 MiniMax 上游账号地址设为 `http://lumivia-canvas-v6k:8080`。转发服务只在 Sub2 的 Docker 网络内监听，保留视频任务和结算的原有流程。Docker 网络名不同的部署可用 `SUB2_DOCKER_NETWORK` 指定。

存储初始使用本地磁盘。启用私有腾讯云 COS 时，在「系统设置」填写完整桶名、桶地域及桶专用凭证，保存前会实际上传一个小测试对象、用签名链接下载并清理测试文件。运行期用加密后的凭证写入对象，下载使用短期签名，浏览器直连默认 COS 域名。可选单独配置一个 HTTPS 预览域名并绑定到桶。没有预览域名时，照片用本地缩略图预览，视频可下载。`canvas.lumivia.cn` 继续用于画布应用。导入画布会按需通过登录校验下载图片。已存在的图像留在原存储位置。

在 `web` 安装锁文件依赖后执行 `bun run typecheck`、`bun test` 和 `bun run build`。后端使用 `PYTHONPATH=lumivia python -m unittest discover -s lumivia/tests`，依赖在 `lumivia/requirements.txt`。发布包包含构建后的 `dist/` 和 `lumivia/`。在香港节点用 `bash lumivia/deploy.sh <tarball>` 部署，脚本先在独立环境安装依赖、验证静态容器并备份画布状态，再切换服务和 Nginx。每个发布目录包含此前的服务配置和状态快照。需要回退时运行 `bash lumivia/rollback.sh <发布目录> <新容器名>`，保留线上数据和已有任务。迁移时同步备份 `/var/lib/lumivia-canvas` 和 `/etc/lumivia-canvas/key-seed`。COS 原图由对象存储单独备份。
